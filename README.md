# arcane_characters
Aplicativo que consulta un endpoint creado sobre personajes de arcane

Lenguaje Utilizado: Dart
Framework: Flutter
Librerias:
-BLoC: Manejador de eventos
-Http: Para realizar peticiones HTTP

El aplicativo realiza una peticion al endpoint de mocky, para luego modelar la respuesta JSON y mostrar info sobre los personajes de arcane.
Actualmente la API no sirve, debido a que la api o JSON creado en Mocky Dejo de funcionar
